Rick Image Style Sampler

28 separate PNG portraits, one per style.

Naming notes:
- "Clay animation" is the generic term; "Claymation" is a trademarked term.
- "Amigurumi crochet" is the appropriate term for the yarn/crocheted character aesthetic.
- Several branded animation/toy aesthetics were given generic filenames to make the pack easier to reuse commercially.
- "Norman Rockwell-inspired" is retained as an art-historical style reference requested for the sampler.
